# Tài liệu Argus Agent

| Tài liệu | Dành cho | Nội dung |
|---|---|---|
| [Hướng dẫn sử dụng](huong-dan-su-dung.md) | Mọi người dùng | Cài đặt, làm quen giao diện, trò chuyện, giao việc nền, tự động hóa, kỹ năng, mô hình AI, Telegram, API, an toàn, sao lưu, xử lý sự cố |
| [Tài liệu dòng lệnh](cli.md) | Người dùng terminal, script | Mọi lệnh `argus`: tùy chọn, ví dụ, biến môi trường, mã thoát, công thức hay dùng |
| [Kiến trúc hệ thống](kien-truc.md) | Lập trình viên | Cấu trúc thư mục, backend, vòng lặp agent, công cụ và phân quyền, các hệ thống con, dữ liệu, API, frontend, bảo mật, cách mở rộng, kiểm thử, triển khai |

Mới bắt đầu? Đọc [mục 2 của Hướng dẫn sử dụng](huong-dan-su-dung.md#2-cài-đặt-và-chạy-lần-đầu), rồi chạy `argus onboard`.

Gặp sự cố? Chạy `argus doctor`, rồi xem [mục Xử lý sự cố](huong-dan-su-dung.md#15-xử-lý-sự-cố).
